# configs

Personal collection of Linux configuration files (dotfiles) and setup scripts.

Includes tiling window managers, modern/terminal based editors, shells, and lightweight desktop tooling. Includes several scripts for installing individual components or bootstrapping a fresh void system.

## Structure

| Path | Description |
|------|-------------|
| `awesome/` | Awesome WM |
| `dwm/` | dwm |
| `i3/` | i3 |
| `niri/` | Niri (Wayland) |
| `openbox/` | Openbox |
| `qtile/` | Qtile |
| `nvim/`, `nvim-lua/`, `nvim_lazy/`, `nvim_old/` | Different Neovim configs |
| `vim/` | Classic Vim |
| `helix/` | Helix editor |
| `zed/` | Zed editor |
| `emacs.d/` | Emacs |
| `zsh_configs/` | Zsh (with autosuggestions, syntax highlighting, liquidprompt) |
| `bashrc/` | Bash |
| `ghostty/` | Ghostty terminal |
| `waybar/`, `wofi/`, `rofi/`, `tint2/` | Bars & launchers |
| `gentoo/`, `nixos/` | Distro-specific configs |
| `picom.conf` | Picom compositor |
| `tmux.conf` | tmux |
